:::{admonition} Benchmark first
:class: benchmark
Start with one slice each from [BEIR](https://github.com/beir-cellar/beir), [FEVER](https://fever.ai/), and [LongMemEval](https://github.com/xiaowu0162/LongMemEval). They expose retrieval, evidence, updates, temporal reasoning, and abstention. Record quality, latency, tokens, storage, and corpus revision from the first prototype; the same cases become regression gates as components change.
:::
